# Allocating Temporaries to "Physical Registers" for the 2ptx-compiler
This is a tutorial on how to allocate temporaries generated from three-address code (TAC) to a finite count of physical registers. The motivation behind this tutorial and its contents is part of my independent study in building a compiler that compiles custom programs to PTX -*Parallel Thread Execution (PTX) is Nvidia's low-level virtual machine and ISA acting as a stable IR for CUDA*-. This tutorial is a continuation of this series, and is the logical next step after the previous tutorial about generating TAC and doing liveness analysis, as liveness analysis is a preliminary phase of register allocation. The ultimate goal, as stated in previous tutorials, is to execute custom fatbin files generated by my compiler using the Nvidia Driver API.

All files this tutorial refers to will be in the ~/2ptx-compiler/ directory.
